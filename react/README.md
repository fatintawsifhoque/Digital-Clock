# ⏰ Digital Clock

A modern digital clock built with React, featuring a sleek glassmorphism design and smooth 12/24-hour format switching.

## 🎯 Features

- **Real-time updates** — Powered by `setInterval` with proper cleanup
- **Format switching** — Toggle between 12-hour (AM/PM) and 24-hour modes
- **Responsive design** — Looks great on any screen size
- **Glassmorphism styling** — Modern frosted glass aesthetic with Tailwind CSS

## 🔧 Built With

- **React 18** (Hooks: `useState`, `useEffect`)
- **Tailwind CSS** for utility-first styling
- **Vite** for instant hot module replacement
