# ⏰ Digital Clock

A beautiful, real-time digital clock built with Vue 3 and Tailwind CSS. It's not just another clock — it's a glassmorphism-styled timepiece that runs smoothly without memory leaks.

## ✨ What Makes It Special

- **Live Time Display** — Updates every second with zero lag
- **12/24 Hour Toggle** — Switch between formats with a single click
- **AM/PM Indicator** — Shows up automatically in 12-hour mode
- **Glassmorphism UI** — Frosted glass effect using Tailwind's `backdrop-blur`
- **Memory Leak Free** — Properly cleans up intervals on unmount using `onUnmounted`

## 🛠️ Tech Stack

- **Vue 3** (Composition API + `<script setup>`)
- **Tailwind CSS** for styling
- **Vite** for blazing-fast development
